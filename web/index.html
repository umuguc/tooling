UMUGUC Tools

During the UMUGUC project, we developed two distinct tools that help with data conversion and visualization.

⇄
HDF5 Converter

This tool views HDF5 files and converts datasets to binary files, and vice versa as needed by the UMUGUC project.

  • Visualize HDF5 files in a user-friendly interface
  • Convert HDF5 datasets to binary files
  • Convert binary files to HDF5 datasets
Open Converter →
◈
Grid Visualizer

This tool visualizes binary files containing 3D point cloud data.

  • Shows 3D point cloud data in an interactive viewer
  • Toggles between tiles and shape factors
  • Example datasets included for quick visualization
Open Visualizer →
